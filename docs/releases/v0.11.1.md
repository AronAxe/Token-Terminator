# Token Terminator v0.11.1 — Hermes live-compression compatibility

A focused patch release of PR #20. The v0.11.0 ContextEngine, learned JEV policy,
Context IR, exact-evidence vault and Observatory remain in place.

## Fixed

- Supply `_coerce_threshold_tokens_cap` for Hermes' live-compression configuration.
- Honor invalidated context-window and threshold caches, explicit pin removal,
  current-route metadata and per-model threshold handling.
- Refresh the engine window from the host's current `select_context` budget
  without resetting retry bindings or usage counters.
- Keep cloned engines' settings independent. No generative compressor, destructive
  history truncation, new key or weakened tokenizer gate is introduced.
- Include nine real-Hermes regression cases and the formatting-only CI correction.

## Upgrade

Use the Python environment actually loaded by your managed Hermes launcher:

```bash
python -m pip install --upgrade 'git+https://github.com/AronAxe/Token-Terminator.git@v0.11.1'
python -m rtk_hermes_plus.cli install-context-engine
```

Keep your existing plugin/engine selection and JEV settings. Once idle, restart
only the relevant backend through its normal supervisor. Do not delete the
conversation history or evidence vault. Verify the imported package path,
loaded version and current-model request metrics, not only a UI percentage.

## Validation and scope

The formatted PR candidate passed Python 3.10–3.13, Windows, packaging, Rust,
learned-policy, ContextEngine, dashboard and Context IR workflows before release
preparation. The learning artifact reported 611 passed and three skips; one
skip is the whole optional real-Hermes test module. Its nine cases were previously
run locally against installed Hermes `188a1a5` on Python 3.14, not counted as
executed in that learning job. Final release-head CI status is recorded on PR #20.
No paid inference or new performance/answer-quality claims accompany this patch.

**Not fixed by this patch:** unknown-model tokenizer support and the separate
host plugin-discovery race. Without an exact target tokenizer, ContextEngine/IR
still pass through. This is not a guarantee that an affected live session has
shrunk, and it does not merge the separate deployed-adapter branch.

README changes are limited to a compatibility note, current install/version
references and correcting the stale FAQ: explicitly selected TT can replace LCM
as Hermes' ContextEngine. Artwork and schematics are unchanged.

The Rust interoperability companion is version-aligned to 0.11.1 without a Rust
behavior change; it is not the Python runtime. GitHub assets include the wheel,
source distribution and SHA256SUMS. Existing releases remain unchanged.
Publication does not install, configure or restart your running agents.
